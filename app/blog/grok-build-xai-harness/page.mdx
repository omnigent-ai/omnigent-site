If you want to put xAI's Grok Build to work next to Claude Code and Codex, it is
now a built-in harness in Omnigent. Pick it the same way you pick any other
agent and drive it in the same UI, with the same sessions and the same policies.

Grok Build used to sit outside your workflow: to run it alongside your other
agents you had to register its launch command yourself. Now you just select the
`grok` harness id and Omnigent drives xAI's `grok` CLI for you, rendering its
streaming output, reasoning, and tool cards and routing its permission requests
through your contextual policies, exactly as it does for the agents you already
run.

Grok Build brings its own credentials and its own model, so install the CLI and
log in through xAI once, then launch it.

```
curl -fsSL https://x.ai/cli/install.sh | bash
grok login --device-auth   # xAI OAuth; or set XAI_API_KEY
omni run --harness grok
```

Omnigent stores no credential and leaves the model choice to Grok. For the full
list of built-in harnesses, see the
[Harnesses guide](/docs/build/harnesses).
