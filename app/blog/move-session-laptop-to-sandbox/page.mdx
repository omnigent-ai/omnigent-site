If you start a session on your laptop and later want it to keep going after you
close the lid, you can now move it onto a new cloud sandbox and carry on the
same conversation there.

Until now, Switch host could only move a session between your own machines, so
getting a running conversation onto cloud compute meant leaving it behind. Now
Switch host offers a new sandbox next to your machines. Omnigent stops the session on your laptop, launches the
sandbox, and the agent continues there with its full transcript. This also
helps when your laptop has gone offline. The reconnect dialog's Switch host
opens the same picker, so you can recover the session onto a new sandbox.

To move a session, open the composer's host menu and choose **Switch host…**.
When your server has managed sandboxes set up, the picker lists a new sandbox
for each provider above your machines. Pick one and optionally enter a
repository URL and branch to clone as the session's working directory. Then
choose **Switch host**. The session shows the sandbox's launch progress, and
any message you send while it provisions waits and is delivered once the
sandbox is ready. The conversation moves with the session but local files do
not, so point it at the repository you want the agent to work in. If the
launch is refused, the dialog stays open and offers your old host again. To set
up sandbox providers on your server, see the
[Cloud Sandbox Host guide](/docs/deploy/cloud-sandbox-host).
