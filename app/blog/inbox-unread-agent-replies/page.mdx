If you keep many agents running at once, you can now check on all of them from
one place. The Inbox lists every session where an agent has replied since you
last looked, with a preview of what it said, alongside the approvals and file
comments that are waiting on you.

Until now, a finished reply only showed up as an unread dot in the sidebar, so
finding out which of your twenty sessions had actually come back meant clicking
through them one by one. The Inbox turns that into a single list. Each item is a
compact card showing the session, whether it finished or hit an error, and the
first line of the latest reply. Items are sorted newest first and grouped by
recency (Just now, Earlier today, Yesterday, This week, Older), so the sessions
that just came back are at the top. This works with any agent you run in
Omnigent.

Three tabs narrow the list. All shows everything. Unread shows agent replies
and file comments you have not seen. Awaiting response shows only the agents
that have stopped to ask you something. The tab you pick is remembered on that
device, so if you only want to see approvals, the Inbox opens that way next
time.

Open the Inbox from the sidebar and click a card to expand it. From there, Open
session takes you into the chat, and Mark as read clears the item without
opening it. Both clear the sidebar's unread dot for that session as well. For
more on the web interface, see the [Web UI guide](/docs/interact/web-ui).
