If you have ACP coding agents registered in OpenClaw or acpx, import their
launch commands into Omnigent instead of adding each one by hand. Each agent
continues to use its own CLI login.

Run `omni setup` and choose **Import from OpenClaw** under **Configure harnesses**:

```bash
omni setup
```

Select the registry at `~/.acpx/config.json` or `~/.openclaw/openclaw.json`, or
choose another file. Review the commands and confirm the import. The agents are
saved in Omnigent's config and become available as `acp:<slug>` harnesses, such
as `acp:gemini-cli`.

To try one agent without saving it to your config, use its registry name:

```bash
omni run --from-openclaw "Gemini CLI"
```

See the [import guide](/docs/build/harnesses/configuration#import-agents-from-openclaw)
for details. For OpenClaw's routing, memory, and channels,
[connect the OpenClaw Gateway](/docs/build/harnesses/configuration#drive-the-openclaw-gateway)
separately.
