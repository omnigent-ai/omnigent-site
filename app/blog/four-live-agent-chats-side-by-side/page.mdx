If you run several agents at once in the desktop web UI, you can now keep up to
four of their live chats on screen together and talk to each one from where it
sits.

Until now, checking on a second agent meant clicking away from the first and
losing sight of it. A session grid puts each chat in its own cell with its own
transcript and composer. You can see which agent is still working, answer the
one that is waiting on you, and redirect another, all from one view. Every cell
shows its session's host, permission mode, and agent. Shift+Tab in a cell's
composer steps that session's permission mode, and if you can edit the session
you can move it to another host from the cell's host menu. A message you send
while an agent is busy waits in that cell's queue until the turn ends, or you
can steer it into the running turn. Drafts and queued messages belong to the
session, so they are still there when you open it full screen. This works with
any agent you run in Omnigent.

Grids are on by default on desktop. Open a session, then drag another session
from the sidebar over it. Hover **Split left**, **Split right**, **Split top**,
or **Split bottom** to preview the layout, and drop. Split a remaining pane
again to reach three or four chats. You can also right-click a sidebar row and
choose **Open in grid**. Grids are saved in this browser, and you can rename
one to find it again from the sidebar. See the
[Web UI guide](/docs/interact/web-ui) for more on working with sessions.
