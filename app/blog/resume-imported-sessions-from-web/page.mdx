If you bring a local Claude Code or Codex chat into Omnigent with `omnigent
import`, you can now open it in the web and keep working, picking the machine it
runs on as you go.

An imported chat is just a transcript. It has no machine attached to it, so
opening it in the web used to look connected while there was nothing behind it
to actually run your next message. Now Omnigent knows an imported session has no
live machine yet, so opening it offers a picker that binds it to a host and
launches a runner before your first message goes out. The picker defaults to the
machine you have online right now, so from any device you can send an imported
chat to whatever machine is currently up.

Import a chat, then click the link the CLI prints to open it in the web:

```
omnigent import --harness claude --session <session-id>
omnigent import --harness codex --session <session-id>
```

The imported session opens with a "Resume on a machine" picker. Its workspace is
prefilled and the host defaults to your one online machine, so you can bind and
send right away. For the full import workflow, see the
[coding agents guide](/docs/use/coding-agents#import-existing-chats).
