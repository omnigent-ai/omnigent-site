If you start an agent on your laptop and want it to keep going on a bigger box, a
work desktop, or a machine that sits closer to the code, you can now hand the
running session off from the web UI without starting over.

The machine a session runs on used to be fixed once it started, so moving work
meant opening a fresh session and losing the thread you were already in. Now the
host badge in the composer shows which machine the session is on, and clicking it
moves that same conversation to another connected machine. The session is
released from its current runner and relaunched on the one you pick, so it keeps
its history and picks up right where it left off.

Click the host badge below the composer to open the Switch host dialog. The next
available machine is already selected and its directory filled in, so the common
case is one click on **Switch host**. You always confirm a directory because
workspaces are per-machine, and the machine the session is already on is left out
of the list. This works with any agent you run in Omnigent, and for more on
managing where a session runs, see the
[Web UI guide](/docs/interact/web-ui#session-management).
