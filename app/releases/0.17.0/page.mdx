# v0.17.0

_Released 2026-10-06_ · Omnigent maintainers

Omnigent 0.17.0 adds desktop OIDC sign-in through your system browser, new keyboard shortcuts, and period-based cost budgets for policies. Review the breaking changes below before upgrading.

## Major new features

### Desktop OIDC sign-in through your system browser

Sign in to OIDC servers through your system browser from the desktop app, with silent renewal, public PKCE clients and explicit provider endpoints, plus operator-set server names shown next to each host.

Learn more about [public PKCE clients and explicit endpoints](/docs/collaborate/auth#public-pkce-clients-and-explicit-endpoints).

([#8897](https://github.com/omnigent-ai/omnigent/pull/8897), [#8894](https://github.com/omnigent-ai/omnigent/pull/8894), [#8895](https://github.com/omnigent-ai/omnigent/pull/8895), [#8898](https://github.com/omnigent-ai/omnigent/pull/8898), [#8776](https://github.com/omnigent-ai/omnigent/pull/8776), [@fanzeyi](https://github.com/fanzeyi), [@dhruv0811](https://github.com/dhruv0811))

### Keyboard shortcuts and sidebar improvements

Keyboard shortcuts for workspace tabs, common views and recent sessions, Ctrl+Shift+L to focus the chat input, a more scannable sidebar agent hierarchy, and optional worktree deletion when archiving a session.

Learn more about [keyboard shortcuts](/docs/interact/web-ui#keyboard-shortcuts).

([#8802](https://github.com/omnigent-ai/omnigent/pull/8802), [#8800](https://github.com/omnigent-ai/omnigent/pull/8800), [#8877](https://github.com/omnigent-ai/omnigent/pull/8877), [#8970](https://github.com/omnigent-ai/omnigent/pull/8970), [#8910](https://github.com/omnigent-ai/omnigent/pull/8910), [#8616](https://github.com/omnigent-ai/omnigent/pull/8616), [@ajayalfred](https://github.com/ajayalfred), [@yaoharry](https://github.com/yaoharry), [@daniellok-db](https://github.com/daniellok-db))

### Period-based cost budgets and richer policy events

Policies gain period-based cost budgets, `conversation_id` in the `PolicyEvent` context, and a `turn_final` indicator for RESPONSE-phase checks.

Learn more about [per-user cost budgets](/docs/policies/builtin#per-user-monthly-or-weekly-quarterly-yearly-budget).

([#5211](https://github.com/omnigent-ai/omnigent/pull/5211), [#8467](https://github.com/omnigent-ai/omnigent/pull/8467), [#8653](https://github.com/omnigent-ai/omnigent/pull/8653), [@terrytangyuan](https://github.com/terrytangyuan), [@ArshSiddiqui](https://github.com/ArshSiddiqui))

## Breaking changes

- `POST /v1/sessions/{id}/switch-agent` now returns 410 Gone; clients that switched a session's agent in place must fork the session into another agent instead ([#8795](https://github.com/omnigent-ai/omnigent/pull/8795), [@dhruv0811](https://github.com/dhruv0811))

To change a session's agent, fork the session into another agent: pass `agent_id` to `POST /v1/sessions/{id}/fork`, or use **Clone session** in the web UI. Learn more about [forking sessions](/docs/programmatic#fork-archive-or-stop-work).
