If you run agents in the Omnigent web UI, you can now start Devin from the New
Chat picker the same way you start any native harness, and configured ACP agents
show up there too.

Before this, starting an ACP agent meant editing an `acp:` config entry and
knowing its slug. Devin is now built in: it appears in the picker and in
`omni setup` with no config file, and configured ACP agents (Devin) and
installed ACP CLI harnesses (Grok Build) sit right alongside your native
harnesses so you pick one and go. Each agent keeps its own login, so Omnigent
stores no credential for it.

To use Devin, log into it once with its own CLI, then pick it from the New Chat
picker, or launch it from the command line:

```bash
omnigent run --harness devin
```

Devin ships via a curl installer and authenticates through its own login:

```bash
curl -fsSL https://cli.devin.ai/install.sh | bash
devin auth login
```

See the [supported harnesses docs](/docs/build/harnesses/supported) for the full
list of agents you can launch this way.
