# Issue triage with Claude Code

Have Claude Code assess a new GitHub issue, explain its classification, and suggest
labels. The workflow checks its JSON response, posts a comment, and applies only
labels from `bug`, `documentation`, and `needs-investigation`.

Follow [Configure Omnigent in GitHub Actions](/docs/programmatic/github-actions)
for installation, credentials, and runner boundaries. Set the `ANTHROPIC_API_KEY`
Actions secret and `CLAUDE_MODEL` repository variable. Create the three labels in
the repository first. This example only processes issues opened by repository
owners, members, or collaborators.

## Workflow

Save as `.github/workflows/triage.yml`. It collects issue metadata, runs Claude Code,
validates output, and checks that the issue has not changed before publication.

<GithubActionsExample file="triage.yml" />

## Agent configuration

Save as `.github/omnigent/claude/config.yaml`. The agent directory and instructions
are shared with [PR review](/docs/programmatic/github-actions/pr-review); the task
prompt tells the agent to perform triage. The workflow maps `ANTHROPIC_API_KEY`
to `MODEL_API_KEY`, which the configuration reads through `executor.auth`.

<GithubActionsExample file="claude/config.yaml" />

## Output validation

Save as `.github/omnigent/validate_output.jq`. Parsing and the string checks support
Markdown formatting; the label allowlist restricts which labels the workflow can
apply. The credential guard rejects model keys in decoded output strings.
