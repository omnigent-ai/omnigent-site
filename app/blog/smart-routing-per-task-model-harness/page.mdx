If you run a mix of tasks and keep second-guessing which model or agent to
start each one on, you can now hand that choice to Omnigent. Pick Auto, type
your first message, and the server reads the task and starts the session on the
harness and model that fit it.

Committing to one model up front means a quick edit and a large refactor both
land on whatever you happened to pick last. Smart Routing removes that guess:
the server asks a router "given this task, which harness and model fit?" and
applies the answer for the rest of the session, so each piece of work runs where
it belongs without you switching anything by hand.

In the web UI, choose **Auto** in the harness picker and send your first
message; the router picks the harness and model from there. From the terminal,
start a session that routes the first message you type inside the harness:

```
omnigent claude --smart-routing
omnigent codex --smart-routing
```

Routing turns on through configuration alone, backed by the server's built-in
judge or an external routing API you point it at. See the
[Smart Routing guide](/docs/build/routing) for setup.
