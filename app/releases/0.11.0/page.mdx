# v0.11.0

_Released 2026-08-25_ · 3 min read · Omnigent maintainers

Omnigent v0.11.0 is a major release focused on giving you tighter control over your agents and a faster everyday flow, from live permission-mode switching on native harnesses to a signed, notarized desktop app. You can now cap what an automation spends on each firing, set a permission mode per scheduled task, drop an emoji on any project, and jump into a new session from anywhere with a single keystroke.

## 1. Full control over native harnesses

![TODO: add a demo screenshot or GIF for "Full control over native harnesses"](TODO)

Native harnesses now behave the way their CLIs do, right inside Omnigent. You can switch Claude Code permission modes on the fly — Manual, Auto, Accept edits, or Plan — with shift+tab or from settings, so you decide how much the agent does before you step in.

The details line up, too. Running `/rename` syncs the new name back to the UI, model pickers show exactly what the claude and codex CLIs report instead of a stale guess, and Codex sessions can run at Max or Ultra reasoning when you want them to think harder.

_Learn more in the [Harnesses](/docs/build/harnesses)._

## 2. Spend caps and permission modes for scheduled tasks

![TODO: add a demo screenshot or GIF for "Spend caps and permission modes for scheduled tasks"](TODO)

Automations now come with real guardrails. Each scheduled task can cap its LLM spend per firing with `max_cost_usd`, so a runaway run can't quietly burn through your budget.

You can also set a Claude Code permission mode per task — for example Accept edits for a task you trust to make changes, or Bypass permissions for a fully hands-off job — so unattended runs behave exactly the way you intend.

_Learn more in the [Scheduled Tasks](/docs/build/scheduled-tasks)._

## 3. A faster web and desktop flow

![TODO: add a demo screenshot or GIF for "A faster web and desktop flow"](TODO)

Getting around Omnigent takes fewer clicks now. Cmd/Ctrl+N starts a new session from anywhere, including the macOS app, and the ⌘K and session-switch hotkeys stay live even when your focus is in the terminal or the composer.

The workspace is tidier as well: the task tracker moves inline as a collapsible "Plan (N/M)" card you can glance at or fold away, and a new session actions menu sits right beside the chat title.

_Learn more in the [Session management](/docs/interact/web-ui#session-management)._
